# ADR-0012: Pack schematic: Sennheiser SK jack pinout, BT40NE pad map, filtered mic bias
Status: accepted. 2026-10-31. Issue #31. Schematic: `hw/pack/pack.py` (SKiDL), BOM `hw/pack/out/bom.csv`.
- **Context:** PK-1 asked to confirm the Sennheiser SK pinout in Phase 4; #31 review asked for an RC-filtered mic-bias rail; ADR-0007 left the BT40NE pinout unverified. Sources: Sennheiser *ew 100 G4 instruction manual*, "Pin assignment", p. 137 (3.5 mm mic plug: **tip = Mic+, ring and sleeve = ground**; line plug: ring = Line+, tip and sleeve = ground); Fanstel *BT40/F/E/N/NE Product Specifications* v1.08, Pin Functions (BT40N/NE use the BT40F pads; 9 pads drive the internal nRF21540); TI PCM1840 SBAS989 (2.5 kΩ per input pin, 2 Vrms *differential* FS, MSZ/FMT/MD pin modes). DPA's own adapter datasheet was not reachable; dealers list the **DAD6034** (MicroDot → locking 3.5 mm) as made for Sennheiser ew "audio and plug-in power".
- **Decision:** J1 tip = MIC (5 V via 2.2 kΩ, R5), ring and sleeve = GND; line plugs are not supported in v1 (R6 is mics only). Mic bias comes from **+5V_BIAS = boost 5 V through 100 Ω + 47 µF** (fc 34 Hz). Jack = Same Sky SJ1-3543 (M6 threaded bushing, $1.61); fallback Switchcraft 35RAPC3BH3 (+$1.68, still ≤ $35). BT40NE: VDD (pad 9) = VDDH (F4) = 3.3 V LDO (nRF5340 normal-voltage mode); USB D+/D−/VBUS on E4/E5/F6; SWD 14–16; I2S BCLK/FSYNC/SDIN on C3/C4/C5 (P0.24/P0.23/P0.20), ADC SHDNZ on D5 (P0.22); battery sense AIN0 (pad 5); LEDs Z0–Z3 (P1.09–P1.12); UART test pads B1/C1. FEM pads Z6 A6 C2 C6 D1 D2 E0 E1 E2 are no-connect; firmware's `nordic,nrf21540-fem` node must use SCK P1.15, MOSI P1.08, MISO P0.25, CSN P1.06, TX_EN P0.21, RX_EN P0.27, PDN P0.26, MODE P1.04, ANT_SEL P1.05. PCM1840: I2S slave (MSZ=0, FMT1=FMT0=1), low-latency filter (MD0=1, R3), DRE on (MD1=1); path 1 (×2) on IN1, path 2 (×1, Q7) on IN2, INxM AC-grounded.
- **Numbers (`tests/test_spice_preamp.py`, ngspice in CI; independent MNA cross-check):** noise 0.94 µV A-wtd (unchanged: the filter's 100 Ω is shunted by 47 µF); 5 V rail → preamp output −33.6 dB at 1 kHz (about −4 dB without the filter; asserted ≤ −30 dB); ADC pin 1.16 V peak at 0.6 Vrms mic, below the 1.41 V peak (1 Vrms) a pseudo-differential input allows. BOM $33.64 at qty 100 ex. cell (`audit.py` asserts ≤ $35); no SPEC number changes.
- **Consequences / Phase 4 signoff items:** (1) fit a real Sennheiser ME 2 plug (or spare plug 099112) and a DPA DAD6034 to the SJ1-3543 thread; if it does not lock, swap to the Switchcraft. (2) Confirm from the EV-BT40NE schematic that the nRF21540 runs from module VDD (3.3 V needed for +19.1 dBm). (3) X8WBT40N grant still unverified (ADR-0007). (4) Single-ended FS of 1 Vrms is inferred from the 2 Vrms differential spec: 1.7 dB headroom on path 1, 7.7 dB on path 2. (5) TPS61023 enters PFM at this ~30 mA load; burst ripple could fall in the audio band: the RC filter alone gives −29 dB at 1 kHz but only −10 dB at 100 Hz (rail → output −14 dB), so bench-check hum/whine in Phase 5. (6) Audio coupling caps are X7R 1206: check THD on the bench; C0G/film if needed.
- **Requirements check:** R6 ✓ (Sennheiser pinout from the manual, 5 V/2.2 kΩ bias; DPA via DAD6034, unverified on the bench) · R5 ✓ (0.94 µV, rail filtered) · R2 ✓ (1.16 V pk < 1.41 V) · R12 ✓ ($33.64) · R7 ✓ (removable 18650, reverse-polarity FET, no charger) · R4 ✓ (recessed slide switch only) · R14 ✓ (4 status LEDs). Jack option "Switchcraft 35RAPC3BH3": same on every row, $1.68 dearer, so the cheaper one wins until the fit test.
